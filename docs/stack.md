# Stack technique

| Brique | Choix |
|---|---|
| Langage | Python 3.11+ |
| LLM | Ollama, `qwen2.5:3b` (local) |
| Embeddings | Ollama, `bge-m3` |
| Base vectorielle | Qdrant (serveur Docker) |
| Orchestration | LangChain + LangGraph |
| MCP | SDK Python `mcp` |
| Backend | FastAPI |
| Interface | React |
| Évaluation | Scripts Python + RAGAS |
| Fine-tuning | Reranker (sentence-transformers) |
